# Sudokutor Game Analysis

A data analysis module for the Sudokutor platform that processes and analyzes Sudoku gameplay data to provide insights into player performance, puzzle difficulty, and solving behavior.

## Overview

This project is designed to collect, process, and analyze gameplay statistics generated by Sudoku players. The goal is to identify patterns in solving strategies, measure puzzle difficulty, and provide meaningful analytics that can improve both player experience and puzzle generation.


## Features

- Import and process Sudoku game session data
- Analyze player solving performance
- Track completion times
- Measure puzzle difficulty metrics
- Generate statistical summaries
- Visualize gameplay trends
- Support for large datasets

## Tech Stack

- Java
- Spring Boot
- Maven
- JPA / Hibernate
- MySQL / PostgreSQL
- REST APIs
- Vite/React

## Getting Started
- Using an OpenRouter API key, connect to the llama LLM
- Start the backend after creating a DB called sudokutor,
- start the frontend:
  ### npm run dev
- choose a difficulty and play

### Prerequisites

- Java 17+
- Maven 3.9+
- MySQL/PostgreSQL

### Installation

Clone the repository:

```bash
git clone https://github.com/ddamjanp/SudokutorGameAnalysis.git
cd SudokutorGameAnalysis
```
